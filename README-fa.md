# esalat-tunnel

تانل اختصاصی ما: **یک باینری، صفر وابستگی** (فقط کتابخانه استاندارد Go).
سمت ایران کلاینت است و فقط از داخل به بیرون وصل می‌شود؛ سمت خارج سرور است و
روی یک پورت گوش می‌دهد. کلاینت‌ها به **IP ایران + همان پورت** وصل می‌شوند، پس
IP سرور خارج هیچ‌وقت در کانفیگ کسی نمی‌آید.

```
کاربر ──► ایران:440 (کلاینت) ==TLS==► خارج:440 (سرور) ──► 127.0.0.1:8443 (VLESS/Reality و هر چیز دیگر)
```

## چرا این و نه rathole/Backhaul/gost

| | rathole | Backhaul | gost | esalat-tunnel |
|---|---|---|---|---|
| زبان/حجم | Rust | Go | Go (ماژول) | **Go، ~۹۰۰ خط** |
| مولتی‌پلکس | ندارد (۱ اتصال به‌ازای هر استریم) | smux | h2/quic | **mux خودمان + flow control** |
| احراز هویت | توکن (مقایسه غیر constant-time) | توکن در لاگ چاپ می‌شود | اختیاری | **توکن constant-time، لاگ نمی‌شود** |
| پروب فعال | پورت مرده نشان می‌دهد | پورت مرده | پورت مرده | **decoy: جواب واقعی HTTPS می‌دهد** |
| تلمتری | ندارد | ندارد | ندارد | **ندارد** |
| متریک | ندارد | پنل بدون auth | Prometheus | **`/stats` JSON فقط روی 127.0.0.1** |
| پین گواهی | ندارد | ندارد | ندارد | **`-pin` (SPKI pin، گواهی پایدار روی دیسک)** |

## نصب (هر سرور یک نقش)

**همان یک دستور روی هر دو سرور** اجرا می‌شود؛ فقط منو می‌پرسد این سرور کدام طرف است.
هر پورتی آزاد باشد درست است — عدد ۴۴۰ فقط یک مثال است:

```bash
# روی هر دو سرور (اول خارج، بعد ایران)
curl -fsSL https://raw.githubusercontent.com/Mehrvarz24/esalat-tunnel/main/esalat.sh | sudo bash
#   1) install → این سرور کدام طرف است؟ abroad یا iran
#     خارج: پروتکل، پورت (هر پورت آزادی)، decoy → توکن و pin چاپ می‌شود
#     ایران: IP سرور خارج، همان پورت، همان توکن، pin، مقصد، تعداد سشن
```

غیرتعاملی با پورت دلخواه (مثلاً ۸۴۴۳):

```bash
# سرور خارج
curl -fsSL .../esalat.sh | sudo bash -s install abroad --transport ws --port 8443 --tune
# سرور ایران
curl -fsSL .../esalat.sh | sudo bash -s install iran --server <IP-خارج> \
     --transport ws --port 8443 --listen :8443 --target 127.0.0.1:8443 --token <TOKEN> --pin <PIN> --tune
```

`install.sh` این کارها را می‌کند:
- باینری را در `/usr/local/bin/easalt` می‌گذارد
- کانفیگ را در `/etc/easalt/<role>.env` (chmod 600) می‌نویسد
- یونیت سخت‌شدهٔ systemd می‌سازد (NoNewPrivileges، ProtectSystem=strict،
  RestrictAddressFamilies، StateDirectory=esalat) و `enable --now` می‌کند
- با `--tune` هم `tune.sh --apply` را اجرا می‌کند
- توکن را بین دو سرور هم‌سان نگه می‌دارد (اجرای دوباره توکن را عوض نمی‌کند)

## بهینه‌سازی (روی هر دو سرور)

```bash
./tune.sh --check     # فقط نمایش وضعیت
./tune.sh --apply     # BBR + fq + بافرهای بزرگ‌تر + fd limit
./tune.sh --dns       # اگر resolver جواب نمی‌دهد: 1.1.1.1 / 9.9.9.9 / 8.8.8.8
```

## گزینه‌های مهم

سرور (خارج):
```
-listen :440              پورت تانل
-token  <secret>          اجباری
-allow  127.0.0.1         فقط به همین پیشوندها وصل می‌شود (ضد open-relay)
-decoy  www.microsoft.com:443   هر ترافیک غیر-تانل به این‌جا می‌رود
-cert-dir /var/lib/esalat گواهی پایدار (پین ثابت می‌ماند)
-stats  127.0.0.1:9101
```

کلاینت (ایران):
```
-server <IP>  -link-port 440  -token <secret>
-listen :440              پورت کاربران
-target 127.0.0.1:8443    مقصد روی سرور خارج
-pin    <SPKI>            گواهی سرور را پین می‌کند (از `easalt pin` یا لاگ سرور)
-sessions 4               تعداد اتصال موازی به خارج (خطی سرعت می‌دهد)
-stats  127.0.0.1:9100
```

## نصبی که روی کلاینت انجام می‌شود

روی سرور خارج فقط سرویس داخلی‌ات را روی `127.0.0.1` بالا بیاور (VLESS+Reality
یا هر چیز دیگر) و `-target` را همان بگذار. لازم نیست هیچ پورتی روی اینترنت باز
شود — نه روی خارج، نه روی ایران (به‌جز همان پورت کاربران روی ایران).

## پروتکل (برای بازبینی)

```
[TCP] [TLS 1.3] [AUTH: "ET1" + token + padding تصادفی]
هدر ۱۰ بایتی: type(1) flags(1) streamID(4) length(4)  little-endian
type: 1=OPEN(مقصد) 2=DATA 3=FIN 4=CREDIT 5=PING 6=PONG 9=AUTH
```
- هر جهت هر استریم با ۱MiB اعتبار شروع می‌شود؛ هر طرف بعد از تحویل بایت‌ها
  CREDIT می‌فرستد → یک استریم کند بقیه را قفل نمی‌کند
- هر سشن هر ۲۰ ثانیه PING می‌زند؛ PONG نیاید سشن بسته و از نو ساخته می‌شود
- decoy: اگر اولین بایت TLS نبود، اتصال به سایت واقعی پاس داده می‌شود

## تست‌های انجام‌شده (روی دو نود قلابی، لوکال)

| تست | نتیجه |
|---|---|
| ۳ بار دانلود ۲۰MB | هش مو‌به‌مو برابر مبدأ ✓ |
| ۲۴ کاربر همزمان | ۲۴×۲۰۰، فقط ۱ هش یکتا ✓ |
| سرعت خام (raw sink) | ۱ نفر ۴.۴ / ۴ نفر ۵.۱ / ۱۶ نفر ۴.۹ Gbit/s |
| خط پایه بدون تانل | ۳۸.۶ Gbit/s |
| توکن غلط | کلاینت چیزی نمی‌گیرد، `errors` بالا می‌رود ✓ |
| پین غلط | اتصال رد می‌شود (گواهی نادرست) ✓ |
| پروب غیر-TLS روی پورت تانل | decoy جواب می‌دهد (سایت واقعی) ✓ |
| ری‌استارت سرور وسط کار | کلاینت خودش برمی‌گردد، دانلود سالم ✓ |
| تحت systemd سخت‌شده | همان نتیجه، پین ثابت بین ری‌استارت‌ها ✓ |

## عیب‌یابی

```bash
systemctl status easalt-iran easalt-abroad
journalctl -u easalt-iran -n 50 --no-pager
curl -s 127.0.0.1:9100/stats   # کلاینت: sessions_live باید = -sessions باشد
curl -s 127.0.0.1:9101/stats   # سرور: streams_open / bytes
```

- `sessions_live: 0` → دیوار بین دو سرور پورت را می‌بندد یا توکن فرق دارد
- سرعت کم → `-sessions` را بالا ببر (هر سشن ~۱.۲Gbit/s روی CPU دو هسته‌ای)
- decoy جواب نمی‌دهد → `-decoy` باید دامنه‌ای باشد که از سرور خارج باز باشد
